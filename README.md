# Pixel Palace Prince

A small pixel platform game inspired by classic palace escape adventures. The
game uses Pillow to generate and animate all pixel-art sprites at runtime, then
shows the frames in a Tkinter window.

## Setup

```bash
python -m pip install -r requirements.txt
```

## Run

```bash
python pixel_prince_game.py
```

## Controls

- Left / Right or A / D: move
- Up or W: jump
- Space: sword attack
- R: restart after winning or losing

Goal: collect the jewel, defeat or avoid the guard, and reach the door.

## Test

```bash
python -m unittest
```
